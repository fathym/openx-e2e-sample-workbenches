# @fathym/e2e-sample-workbench-no-port

Test fixture for OpenX e2e. Not for use.

A workbench whose one mode, the built-in `Web`, declares no `.Ports(...)` at all, on purpose. OpenX refuses to save it, naming `Web` and where to fix it. The OpenX e2e journey `no-port-save-error-names-the-mode` reads that refusal.

The version is pinned by the journey and never moves.
